### Handover Context for Next Chat: Notification System & Architecture Updates

**1. Primary Topic for New Chat: Notification & Logging Architecture**

* **Problem:** Math and calculation modules (like `stations.py`) directly depend on GTK UI context via `Gtk.Application.get_default()` and `notify_manager`. This couples pure astronomical calculations to UI execution, breaking headless execution, testing, and clean error handling.


* **Goal:** Replace direct UI/GTK calls in engine/math modules with standard Python `logging` (`logger.debug`, `logger.error`, etc.).
* **UI Integration:** Design a custom `LoggingHandler` attached at the GTK application level that intercepts standard log records and routes them directly to `notify_manager` or the terminal based on log level.

**2. Standardized Terms & Formatting**

* **`astro_glyph`**: The actual unicode/font character rendered from the custom font (e.g., `VictorMonoLightAstro`).
* **`plain_text`**: Clean, human-readable string used for notifications, clipboard exports, logging, and tooltips (`"jupiter"`, `"retro"`, `"h12"`).
* **`glyphs.resolve(key)`**: Unified lookup function returning `(astro_glyph, plain_text)` across all glyph registries.

**3. Engine & Drawing Refactoring Decisions**

* **Snap Coordinates (`rings.py` $\rightarrow$ `angleruler.py`):**
* `rings.py` acts as the single source of truth for visual object locations.
* During its draw pass, `rings.py` will publish calculated positions into `chart.snap_targets = [(lon, x, y, astro_glyph, plain_text, ring_name), ...]`.
* `angleruler.py` will query `chart.snap_targets` directly, eliminating duplicate position, latitude, and ring calculations.




* **Stations Calculation (`stations.py`):**
* **Explicit Direction States:** Support directional station flags (`SR` for Stationary Retrograde, `SD` for Stationary Direct, `R` for Retrograde, `' '` for Direct) by checking velocity delta ($\Delta JD \pm 0.1$).
* **Cache Invalidation:** Change `last_stations` cache key from `body` to `(body, round(jd_ut, 2))` to prevent date bleeding across charts or progressions.


* **Decoupling:** Convert calculation signatures to accept explicit parameters (`jd_ut`, `selected_objects`, `use_mean_node`) rather than reading off the GTK `app` instance.
